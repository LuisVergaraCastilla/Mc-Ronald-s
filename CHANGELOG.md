# CHANGELOG

Registro de cambios del sistema Mc Ronald's para gestión de pedidos en restaurantes de comida rápida.

---

## [1.0.0] - 2025-10-20

### Added
- Configuración inicial del backend con Spring Boot.
- Estructura base del frontend con React + Vite.
- Integración de base de datos MySQL.
- Seguridad con Spring Security y JWT.
- Roles definidos: ADMIN y COCINERO.
- Pantalla de pedidos para clientes invitados.
- Métodos de pago: tarjeta y Yape.
- Generación de boleta/factura.

### Changed
- Flujo de trabajo con ramas `feature/`, `fix/`, `develop-Nombre`.

### Fixed
- Validación de contraseña en registro.
- Conflictos en `Header.jsx` al fusionar ramas.

---

## [0.1.0] - 2025-09-01

### Initial
- Inicio del proyecto.
- Configuración de repositorio y estructura de carpetas.
- Primer commit con base de Spring Boot.
